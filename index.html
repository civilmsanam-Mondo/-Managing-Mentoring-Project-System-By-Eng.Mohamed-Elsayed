Multi-Device Sync — Supabase
ⓘ Setup Instructions (click to collapse)

Step 1 — Create the database table:

In Supabase → left menu → SQL Editor → paste and click RUN:

CREATE TABLE IF NOT EXISTS site_data ( id int PRIMARY KEY, payload text, updated_at timestamptz DEFAULT now() ); ALTER TABLE site_data DISABLE ROW LEVEL SECURITY;

Step 2 — Get your Project URL:

Settings → General → copy the Project URL (e.g. https://xxxx.supabase.co)

Step 3 — Get your API Key:

Settings → API Keys → under "Secret keys"

Click the eye icon 👁 next to sb_secret_... to reveal it → copy it

Or use tab "Legacy anon, service_role API keys" → copy service_role key

Step 4 — Connect:

Paste URL + Key below → Test Connection → Save & Sync ✔

📄 Offline Alternative — if jsonbin.io is blocked on your network, use Export/Import instead:

Supabase free tier — 500MB storage — use Secret Key (sb_secret_...) for full access
